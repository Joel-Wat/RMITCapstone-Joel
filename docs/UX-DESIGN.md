# UX Design – Login and Team Page

## UX Designer
Diya Diljith

## Design Deliverables

The UX design covers the styled login experience and team page required for the Mock Sprint.

### Login Page
- Styled login interface
- Email and password fields
- Purple gradient visual theme
- Clear login and sign-up actions
- Consistent navigation and footer

### Team Page
- Team name
- Team member selection
- Member photo
- Member name
- Member role
- Short member description
- Placeholder avatar when a photo is unavailable
- Layout supporting longer descriptions
